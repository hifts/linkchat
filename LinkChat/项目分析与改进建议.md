**为什么重要：**
- 这是网络编程的**核心技能点**，面试必问
- 体现对TCP连接管理的理解
- 实际项目中必不可少

**实现建议：**
```cpp
// 客户端：每5秒发送心跳包
QTimer *m_heartbeatTimer;
connect(m_heartbeatTimer, &QTimer::timeout, [=](){
    NetworkManager::instance().sendMsg(MSG_HEARTBEAT, QByteArray());
});

// 服务端：15秒未收到心跳包则断开连接
QTimer *m_timeoutTimer;
// 每次收到心跳包重置定时器
```

**协议定义：**
```cpp
enum MessageType {
```

## 💡 面试准备要点

### 可能被问到的问题：

1. **"TCP粘包问题你是怎么解决的？"**
   - 回答：使用固定长度协议头（PDUHeader），包含total_len字段，接收端先读头部，再根据长度读取完整包体。

2. **"文件传输为什么用多线程？"**
   - 回答：大文件传输会阻塞主线程，导致UI卡顿。使用QThread在后台传输，通过信号槽更新进度条。

3. **"心跳包的作用是什么？"**
   - 回答：检测连接是否存活。TCP连接可能因为网络问题"假死"，心跳包可以及时发现并重连。

4. **"你的协议设计有什么考虑？"**
   - 回答：使用固定头部结构，包含消息类型、源ID、目标ID，便于路由和扩展。使用字节对齐确保跨平台兼容。

5. **"如何保证消息不丢失？"**
   - 回答：离线消息存储到数据库，用户上线后推送。历史消息持久化存储。
