# 文件传输功能使用说明

## 功能特性

✅ **多线程传输** - 不阻塞UI界面，保持流畅体验
✅ **文件切片** - 64KB分片，支持大文件传输
✅ **进度显示** - 实时显示传输进度
✅ **断点续传准备** - 记录分片信息，为未来断点续传做准备
✅ **错误处理** - 完善的错误处理和用户提示
✅ **文件限制** - 默认限制100MB，可调整

## 使用流程

### 发送文件

1. 选择一个好友进行聊天
2. 点击输入框旁的"文件"按钮（或📎图标）
3. 选择要发送的文件
4. 系统自动开始传输
5. 可在聊天记录中看到传输状态

### 接收文件

1. 收到文件传输请求时，会弹出确认对话框
2. 显示文件名、大小等信息
3. 点击"Yes"接收，"No"拒绝
4. 接收的文件自动保存到系统"下载"文件夹
5. 传输完成后显示保存路径

## 技术实现

### 架构设计

```
MainWindow (UI层)
    ↓
FileTransferManager (管理层)
    ↓
FileTransferWorker (工作线程)
    ↓
NetworkManager (网络层)
    ↓
Server (转发层)
    ↓
FileReceiver (接收层)
```

### 核心类说明

#### 1. FileTransferWorker
- 运行在独立线程中
- 负责读取文件并切片
- 发送进度更新信号
- 可随时取消传输

#### 2. FileTransferManager
- 单例模式管理所有传输任务
- 维护传输状态
- 处理多个并发传输
- 连接Worker和UI

#### 3. FileReceiver
- 单例模式管理所有接收任务
- 处理文件分片写入
- 检测重复分片
- 自动完成文件组装

### 协议设计

#### 传输流程

```
发送端                     服务器                     接收端
  |                          |                          |
  |--MSG_FILE_TRANSFER_REQ-->|                          |
  |                          |--MSG_FILE_TRANSFER_REQ-->|
  |                          |                          |
  |                          |<--MSG_FILE_TRANSFER_RESP-|
  |<--MSG_FILE_TRANSFER_RESP-|                          |
  |                          |                          |
  |----MSG_FILE_CHUNK(1)---->|                          |
  |                          |----MSG_FILE_CHUNK(1)---->|
  |----MSG_FILE_CHUNK(2)---->|                          |
  |                          |----MSG_FILE_CHUNK(2)---->|
  |          ...             |            ...           |
  |----MSG_FILE_CHUNK(N)---->|                          |
  |                          |----MSG_FILE_CHUNK(N)---->|
```

#### 消息类型

- `MSG_FILE_TRANSFER_REQ (0x0011)` - 文件传输请求
- `MSG_FILE_TRANSFER_RESP (0x0012)` - 文件传输响应
- `MSG_FILE_CHUNK (0x0013)` - 文件分片数据
- `MSG_FILE_TRANSFER_ACK (0x0014)` - 文件传输确认
- `MSG_FILE_TRANSFER_CANCEL (0x0015)` - 取消文件传输

### 性能优化

1. **分片大小**: 默认64KB，平衡内存和网络效率
2. **发送延迟**: 每个分片间隔10ms，避免网络拥塞
3. **日志优化**: 每10个分片输出一次日志，减少I/O
4. **内存管理**: 及时释放已发送/接收的分片数据

## 配置参数

### 可调整参数

```cpp
// 在 FileTransferWorker 中
m_chunkSize = 64 * 1024;  // 分片大小（64KB）

// 在 MainWindow 中
if (fileInfo.size() > 100 * 1024 * 1024) {  // 文件大小限制（100MB）
    // 拒绝发送

// 在 FileTransferWorker::startTransfer() 中

```

## 常见问题

**Q: 为什么传输会失败？**
A: 可能原因：
- 网络连接中断
- 对方离线
- 磁盘空间不足
- 文件读写权限问题

**Q: 如何提高传输速度？**
A: 
- 减少分片间隔时间
- 增大分片大小
- 优化网络环境

**Q: 文件保存在哪里？**
A: 接收的文件默认保存在系统"下载"文件夹，路径会在传输完成时显示。

**Q: 可以同时传输多个文件吗？**
A: 当前版本支持多个文件并发传输，但建议不要同时传输过多文件以保证速度。
